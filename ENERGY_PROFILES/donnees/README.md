# Ressources d'exploration — Energy Profiles

Ce dossier rassemble des ressources d'exploration fictives pour le projet LocalMind.

## Documents à explorer

Le dossier `sources_documentaires/` contient 2 profils pays différents :

- `Enerdata_Energy_Report_CZ_EXTRACT.pdf` : république tchèque;
- `Enerdata_Energy_Report_MY_EXTRACT.pdf` : Malaysie;

ps : le repo publique ne contient que des extraits des documents complets (cf TOC)


## Exemples de consignes

Le dossier `exemples_prompts/` propose deux variantes de consignes de résumé (`prompt_v1.txt` et `prompt_v2.txt`). Elles comportent l'emplacement `{document}` à substituer.

## Cas d'évaluation

Le fichier `jeux_evaluation/eval.csv` associe, pour chaque document, un résumé de référence (à compléter). Ses colonnes sont `eval_id`, `document` et `reference_summary`.

Tous les fichiers fournis sont des exemples réels.
