# Ressources d'exploration — LocalMind

Ce dossier rassemble des ressources d'exploration fictives pour le projet LocalMind.

## Documents à explorer

Le dossier `sources_documentaires/` contient des documents de tailles variées :

- `compte_rendu_reunion_produit.txt` — court (une page) ;
- `politique_teletravail.md` — moyen ;
- `rapport_activite_2025_fondation_lumen.md` — long.

Vous pouvez les compléter avec vos propres documents de test, y compris des PDF si vous souhaitez explorer leur lecture.

## Exemples de consignes

Le dossier `exemples_prompts/` propose deux variantes de consignes de résumé (`prompt_v1.txt` et `prompt_v2.txt`). Elles comportent l'emplacement `{document}` à substituer.

## Cas d'évaluation

Le fichier `jeux_evaluation/eval.csv` associe, pour chaque document, un résumé de référence. Ses colonnes sont `eval_id`, `document` et `reference_summary`.

Tous les fichiers fournis sont des exemples fictifs.
